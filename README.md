# Passport Holsters Genitron Database

Replacement database sourced exclusively from Genitron.com. Do not merge in prior CSVs, aliases, or records from the superseded database.

Schema: Manufacturer, Model, Barrel Length (inches), Passport Fit Size.

One row represents a specific Genitron model/variant when Genitron lists variants separately. Fit assignments follow the Passport Holsters sizing chart. Genitron record URL is retained in the CSV for traceability.

This is an in-progress replacement; only individually checked records belong here.
