# Popular model search coverage (2026-10-28)

Search identities and aliases for the six main picks and two honorable mentions in
https://www.pewpewtactical.com/best-handgun-beginners-home-defense/ (reviewed 2026-10-28).
This reference identifies customer search phrases, not PHolsters compatibility.

New combined/specific variants are deliberately unconfirmed: fit_verified=0 and
passport_fit is blank. No dimensions or fits are inferred from a family model.
Existing Walther PDP, Canik METE SFT ONE and CZ P-10 C review identities are reused.
Smith & Wesson/S&W and SIG Sauer/SIG spelling forms normalize consistently.

Typing uses suggest=1 to retain generation/variant choices after an exact family
alias is found. Submitting a search retains exact-model precedence. For example,
Glock 19 suggestions include Gen 1–5, MOS, and Gen 5 MOS; exact Glock 19 still
returns the two generic chart choices. Selecting a variant never inherits them.
