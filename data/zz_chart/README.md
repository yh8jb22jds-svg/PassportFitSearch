# Chart-listed fit entries (2026-11-05)

This batch adds 162 explicit model listings from the [Passport Holsters size chart](https://pholsters.com/size-chart/) as importer-ready records. Only a model appearing as a discrete chart listing with one unambiguous size category was included. The `variant` column identifies the chart's barrel-length category; it is not a measured specification for every generation or configuration. Confirm the customer's exact barrel length and accessories before ordering.

Entries appearing in more than one size category, composite/garbled chart lines, and the misplaced handgun lines in the R2.5 revolver section were excluded. No proposed fit from a review CSV was promoted merely because it said “Approved” or “exact match.” Existing exact firearm IDs are reused where possible so their aliases point to the confirmed chart listing. The new CHART IDs cover models absent from the review files.

This dataset does not certify newer generations, optics, lights, or altered configurations. The source chart and these records should be reviewed together when the chart changes.

The four A2.5 subcompact listings (Glock 27, Glock 33, Springfield XD9 Sub-Compact, and Walther P22 with a 3.4-inch barrel) were added from the semi-automatic A2.5 section. The same handgun names accidentally appear under the R2.5 revolver heading; that misplaced copy does not turn them into revolvers. Walther is spelled “Walter” in that chart line; the search recognizes both spellings.
